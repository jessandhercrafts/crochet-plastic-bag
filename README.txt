CROCHET PLASTIC BAG — WEBSITE (PUBLISH VERSION)

This folder is ready for GitHub Pages. No build tools or paid hosting are needed.

1. Create a public GitHub repository named crochet-plastic-bag.
2. Unzip the website package on your computer.
3. In the repository, select Add file > Upload files (or the upload prompt in an empty repository).
4. Upload the CONTENTS of this folder, not the ZIP itself:
   index.html, style.css, script.js, README.txt, and the assets folder.
   IMPORTANT: assets/pattern-watermarked.png and assets/brand-logo.png must retain those paths.
5. Commit changes to the main branch.
6. Settings > Pages > Build and deployment > Source: Deploy from a branch.
   Choose main and /(root), then Save.
7. Open the URL shown in the Pages settings once deployment finishes.
   It will look like https://YOUR-USERNAME.github.io/crochet-plastic-bag/

ARTWORK
- assets/pattern-watermarked.png is the confirmed 2108 x 2625 PNG (RGB).
- assets/brand-logo.png is the brand logo.

REMINDERS
- GitHub Pages on a public repo means all uploaded assets can be accessed.
- Right-click protection is only a deterrent; browser tools/screenshots may obtain images.
- Test pinch gestures on a real phone after publishing.
